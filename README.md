# CatppuccinFocusTheme
A custom theme for [focus-editor](https://github.com/focus-editor/focus) based on [catppuccin (mocha)](https://catppuccin.com/).

## Instalation
Literally just copy-paste this file into your focus config directory, then select the theme "catppuccin" (Ctrl + Shift + P, then "Choose Theme").

## Corrections
If anything is wrong with the color scheme, the theme file or this readme please open an issue.
